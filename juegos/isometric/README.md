# Isometric Tactics — Web build

Build web export of [Nico Rueda's Godot project](https://github.com/NicoRuedaA/G.-Isometric), generated from source commit `f537f0d11198d9cc623f6e1919149d34bb8b0d84` with Godot 3.6.3-stable.

## Controls

- Left click: select.
- Mouse wheel: zoom in or out.
- Escape: pause.

The exported build is served at <https://nicorueda.dev/juegos/isometric/>.
